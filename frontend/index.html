How It Works

Our backend document engine processes complex tables in four automated steps.

01

PDF Rendering & Orientation

PyMuPDF renders PDF pages to 300 DPI high-res images and automatically detects 0°, 90°, 180°, or 270° rotation.

02

Preprocessing & PaddleOCR

CLAHE contrast enhancement sharpens text and preserves table lines before extracting precise text bounding boxes.

03

Hybrid Cell Reconstruction

Spatial geometry groups text into logical rows and columns, merging names, dates, and order numbers into single cells.

04

Interactive Review & XLSX

Review and edit extracted values directly in the browser spreadsheet before downloading a formatted OpenPyXL spreadsheet.

Key Features

🔄 Rotated Table Auto-Correction

Handles sideways 90-degree and upside-down scanned reports effortlessly before running character recognition.

📑 Multi-Page Header Merging

Processes multi-page reports into a single consolidated table, automatically stripping repeated page headers.

🔢 ID Leading Zero Preservation

Patient IDs, Order Numbers, and Visit Numbers are explicitly formatted as text to prevent Excel digit truncation.

🔒 Enterprise Privacy & Zero Data Retention

Uploaded PDF documents are processed strictly on your application server backend. Intermediate rendered page images, temporary OCR artifacts, and temporary uploaded PDF files are automatically deleted after conversion and download.
