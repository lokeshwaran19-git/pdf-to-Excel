Key Features

Rotated Table Auto-Correction

📑

Multi-Page Header Merging

Processes multi-page reports into a single consolidated table, automatically stripping repeated page headers.

ID Leading Zero Preservation

About

PDF to Excel is a production-quality full-stack application that uses PyMuPDF, PaddleOCR, and OpenPyXL to extract structured data from rotated, scanned, and image-based PDF reports — converting them into properly formatted Excel spreadsheets.
